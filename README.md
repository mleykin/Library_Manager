# Library Manager

Консольное приложение для управления коллекцией книг. Позволяет создавать, редактировать, искать, сохранять и загружать книги из файла.

## Команды:

- create — добавить новую книгу
- list — показать все книги
- find — найти книги по атрибуту (имя, автор, жанр, дата)
- edit — изменить данные книги
- save — сохранить коллекцию в файл
- load — загрузить коллекцию из файла
- clear — очистить коллекцию
- help / ? — показать справку
- \# — выйти из любого процесса

## Формат сохранения файлов:

Коллекция сохраняется в файл с расширением `.txt` в виде сериализованного списка объектов `Book`.
